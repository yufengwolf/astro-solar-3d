外链直达清单

三层链接：3D 页面（介绍太阳系 / 银河系这类整页）、宇宙层级节点（可观测宇宙、本星系群、仙女座星系…）、单个天体（打开即聚焦、信息卡展开、镜头跟着天体继续运动）。
下面的完整地址自动套用当前站点前缀 ，本地与线上部署通用。

参数说明

  • 页面级：galaxy.html / solar.html 直接打开整页；也可用 go.html?page=galaxy。
  • 层级节点：cosmos.html?node=localgroup（本星系群）或万能入口 go.html?node=milkyway（银河系）。注册表里每个节点都有独立链接，新增星系 / 恒星系统自动进表。
  • ?body=<ID>：天体直达。ID 全局唯一时可直接用短名；跨页同名用 页面:ID（如 jupiter:jupiter）。go.html?body=<ID> 只记 ID 即可。
  • &embed=1：精简嵌入模式，隐藏导航、菜单、控制面板；点「复制嵌入代码」已自动带上。
  • &lang=en：英文界面。#earth 形式的锚点同样可用，且可在不刷新页面的情况下切换天体。
  • 银河系页的恒星远看只是一个点，直达链接会自动把镜头推进到近景，看到球面与日冕；继续滚轮放大也能得到同样效果。
  • 链接只依赖域名前缀之后的路径，换域名不需要改；机器可读版本见 links.json。
